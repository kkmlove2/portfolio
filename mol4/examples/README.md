# MOL4 Code Examples

실제 서비스 소스 전체를 공개하는 대신, 포트폴리오에서 설명한 담당 기능의 설계와 구조를 이해할 수 있도록 **단순화·재구성한 예제 코드**입니다.

> 실제 프로젝트의 원본 코드가 아니며, 회사/서비스 고유의 모델·API·구현은 포함하지 않습니다.

## Examples

- `FavoriteGroupController.kt` — Favorite Group의 추가/이름 변경/삭제 구조
- `PinnedGroupController.kt` — Pinned Group의 Pin/Unpin/순서 변경 구조
- `ProfileFlowExample.kt` — Profile 생성/수정/전환 흐름의 단순화된 예제

### 포트폴리오에서 보여주고 싶은 부분

- 기존 코드 구조를 이해하고 필요한 책임을 분리하는 방식
- Group 상태 변경과 UI 갱신을 연결하는 흐름
- Android TV 환경에서 관리 화면의 사용자 흐름을 구성하는 방식
