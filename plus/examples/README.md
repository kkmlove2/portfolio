# MyTVOnline+ Code Examples

실제 서비스 소스 전체를 공개하는 대신, 포트폴리오에서 설명한 담당 기능의 UI 구조와 사용자 흐름을 이해할 수 있도록 **단순화·재구성한 예제 코드**입니다.

> 실제 프로젝트의 원본 코드가 아니며, 회사/서비스 고유의 모델·API·구현은 포함하지 않습니다.

## Examples

- `HomeScreenExample.kt` — Home UI를 Compose로 구성하는 단순화 예제
- `LiveScreenExample.kt` — Channel / Group / EPG 탐색 UI의 상태 흐름 예제
- `ProfileFlowExample.kt` — Profile 생성/수정/전환을 연결하는 예제

### 포트폴리오에서 보여주고 싶은 부분

- Compose 기반 UI 구성
- 화면 상태와 사용자 흐름의 연결
- 기능별 Navigation 구조
- Profile 상태를 화면과 연결하는 방식
